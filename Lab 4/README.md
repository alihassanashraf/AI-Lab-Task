# AI Lab 4 - Informed Search: Heuristics & A*

This package contains the written report, PDF copy, runnable Python source, input data, captured output, and diagrams for CAI601400 Lab 4. The graph, edge weights, heuristic values, true remaining costs, start node, and goal node follow the supplied lab manual.

## Files

- `Doc2.docx` - editable report with manual calculations, heuristic audit, A*/UCS comparison, overestimate experiment, failure analysis, reflection, responsible-practice responses, measurable outcome, and responses to the faculty self-check prompts.
- `lab4_astar_audit.py` - runnable A* implementation, UCS control run, trace generation, independent path-cost checks, and heuristic audit.
- `lab4_input.json` - graph, edge costs, start/goal, supplied heuristic, and true remaining costs.
- `lab4_output.txt` - output and traces generated by the Python program.
- `README.md` - setup, run, and submission instructions.
- `Diagram_Guide.md` - step-by-step instructions for redrawing the four diagrams by hand.

## Diagrams included

1. `figure_1_campus_graph.png` - supplied weighted directed campus graph and heuristic values.
2. `figure_2_astar_flowchart.png` - high-level A* search flowchart.
3. `figure_3_frontier_trace.png` - frontier after the first three A* expansions.
4. `figure_4_overestimate_comparison.png` - original and modified heuristic comparison.


## Run on Windows

1. Extract this ZIP file.
2. Open PowerShell or Command Prompt in the `AI_Lab4_Solution` folder.
3. Run:

```powershell
py lab4_astar_audit.py
```

Python 3.8 or newer is recommended. No third-party Python packages are required. The program reads `lab4_input.json`, prints the traces, and creates/overwrites `lab4_output.txt` in the same folder.

## Verified results

- A* with the supplied heuristic: `S -> A -> C -> G`, cost `6`, expansion count `3`.
- UCS with `h(n)=0`: `S -> A -> C -> G`, cost `6`, expansion count `4`.
- A* with modified `h(C)=10`: `S -> B -> G`, cost `9`, expansion count `3`.
